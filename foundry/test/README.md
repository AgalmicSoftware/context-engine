# foundry/test/

Forge test suites: `*.t.sol`, `*.fuzz.t.sol` and `*.invariant.t.sol`, plus shared
helpers such as `TestUtils.sol`. Run them with `npm run test:contracts`.

Root Node/Jest tests for workers, deploy helpers and integration harnesses live in
[`../../tests/root/`](../../tests/root/). [`../../tests/README.md`](../../tests/README.md)
says where each kind of test goes.
