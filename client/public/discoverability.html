Context Engine

Context Engine is an open-source toolkit for AI-enhanced deliberation and large-group sensemaking. It supports public and private questions and responses, AI-assisted input and analysis, permanent records, and cryptographic access control.

The project includes survey authoring and response workflows, SBT-gated groups, passkey-based user onboarding, Cloudflare Worker support, and an OSS GitHub repository.

Summary

Context Engine is designed for large-group deliberation, survey-based sensemaking, and cryptographically gated access to content and results. The platform supports AI-assisted input, persistent storage, and group-oriented participation flows.
