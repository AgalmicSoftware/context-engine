Context Engine

Context Engine is an open-source toolkit for AI-enhanced deliberation and large-group sensemaking. It supports public and private questions and responses, AI-assisted input and analysis, configurable storage, and encrypted fields with gated access.

The project includes survey authoring and response workflows, Worker-native and SBT-gated groups, passkey sign-in, a per-session Cloudflare Worker, scoped Agent HTTP, and an open-source GitHub repository.

Summary

New sessions start on Hosted & Fast: a creator-owned per-session Cloudflare Worker with Cloudflare storage, public results, and unencrypted answers. Choosing encryption or another results visibility keeps them private. Trustless & Slower is an opt-in path that adds public EVM contracts, wallet transactions, and Arweave, and still uses a Session Worker. Company-Operated is planned. EVM and Arweave are profile-specific options rather than baseline dependencies.

Agents use scoped HTTP at /api/agent/* on the Session Worker. Browser automation can use stable TestIDs; development and E2E builds also offer an opt-in bridge.
