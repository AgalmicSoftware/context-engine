Context Engine

Context Engine is an open-source toolkit for AI-enhanced deliberation and large-group sensemaking. It supports public and private questions and responses, AI-assisted input and analysis, permanent records, and cryptographic access control.

The project includes survey authoring and response workflows, SBT-gated groups, passkey-based user onboarding, Cloudflare Worker support, a deterministic browser TestID API, a dev agent bridge, and an OSS GitHub repository.

Summary

Context Engine is designed for large-group deliberation, survey-based sensemaking, and cryptographically gated access to content and results. The platform supports AI-assisted input, persistent storage, group-oriented participation flows, and an emerging agent-facing surface through stable docs, TestIDs, and the local `contextEngine-cc` companion.
