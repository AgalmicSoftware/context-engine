# Poppins

The app self-hosts Poppins, its body and button font, so no page asks a font
service for it.

- Source: npm package `@fontsource/poppins` 5.3.0, files unchanged
- Files: weights 400, 600, 700 and 800, normal, in the latin, latin-ext and
  devanagari subsets the package splits by `unicode-range`
- License: SIL Open Font License 1.1; see `OFL.txt`
