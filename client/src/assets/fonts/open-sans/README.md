# Open Sans

The `civic` and `context-engine` themes self-host Open Sans so no page asks a
font service for it.

- Source: npm package `@fontsource-variable/open-sans` 5.3.0, files unchanged
- Files: the weight-axis (300–800) variable fonts, normal and italic, in each
  subset the package splits by `unicode-range`
