# Wine Tahoma

The Classic 95 app theme self-hosts Wine's Tahoma-compatible regular and bold
fonts so the UI does not depend on an operating-system font or a remote font
service.

- Upstream: <https://github.com/wine-mirror/wine/tree/f3d2cbcff79ac0dc0e212d90484755a9340964ba/fonts>
- Upstream revision: `f3d2cbcff79ac0dc0e212d90484755a9340964ba`
- Upstream files: `fonts/tahoma.ttf`, `fonts/tahomabd.ttf`,
  `fonts/tahoma.sfd`, and `fonts/tahomabd.sfd`
- License: `LGPL-2.1-or-later`; see `COPYING.LIB`
- Copyright notice: Copyright (c) 2004 Larry Snyder. Based on Bitstream Vera
  Sans, Copyright (c) 2003 Bitstream, Inc. The font was renamed in accordance
  with the upstream license.

The `.sfd` sources in `source/` correspond to the two bundled TrueType files.
The files are redistributed unchanged from the upstream revision above.
