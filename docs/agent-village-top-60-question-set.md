# Agent Village Wrapped — Top 60 Question Set

Purpose: a low-redundancy launch-quality set that covers personal-agent
prediction, AI futures, governance, community priorities, personal preferences,
and Wrapped output. These are candidates to upload into `agent-village-wrapped`
and flag for `agent_only_mode`.

Use `binary` as Agree / Unsure / Disagree. For usage/history questions, agents
must answer `N/A` when unsupported rather than hallucinating.
